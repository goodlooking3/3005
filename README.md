# واصل — مساحة العمل المالية

مستودع خاص مؤرخ في **2026-10-01** لتطبيق Flutter عربي RTL يجمع الأرشيف، المحاسبة، المحفظة، إدارة المخزون والمشتريات. هذه النسخة أُعدت لمراجعة واجهات التطبيق وتشغيل تفاعلات محلية في المتصفح؛ **ليست نشرًا إنتاجيًا ولا تتصل بخادم أو قاعدة بيانات سحابية**.

## معاينة Flutter Web محليًا

المعاينة تعمل على `localhost` فقط، وتستخدم SQLite/WASM مع تخزين متصفح دائم (IndexedDB). عند تشغيل وضع المراجعة تظهر بيانات توضيحية تلقائيًا **فقط إذا كانت قاعدة المتصفح فارغة**. لا تدخل معلومات مالية حقيقية.

```bash
flutter pub get
# يلزم تنزيل sqlite3.wasm والعامل مرة واحدة بعد جلب الاعتماديات
dart run sqflite_common_ffi_web:setup
flutter run -d web-server \
  --web-hostname 127.0.0.1 \
  --web-port 8080 \
  --dart-define=WASEL_WEB_REVIEW=true \
  --dart-define=WASEL_LOCAL_ONLY=true
```

افتح `http://127.0.0.1:8080`. أنشئ حساب معاينة محليًا، ثم استخدم التنقل لمراجعة الأرشيف، المحاسبة، المحفظة، المبيعات والمشتريات. تبقى قاعدة البيانات ضمن ملف تعريف المتصفح وعنوان الموقع نفسيهما؛ حذف بيانات الموقع من إعدادات المتصفح يعيد المعاينة إلى حالتها النظيفة.

### بناء ملفات الويب محليًا

```bash
flutter build web --release \
  --dart-define=WASEL_WEB_REVIEW=true \
  --dart-define=WASEL_LOCAL_ONLY=true
```

تُنشأ الملفات في `build/web/`. لا ينشر هذا الأمر الملفات ولا يرفعها. في نسخة البناء هذه تُستعمل منصة الويب العادية لـFlutter، ويحمّل sqflite محرك SQLite/WASM الخاص به. تحذيرات فحص **Flutter app-Wasm** المتعلقة ببعض الاعتماديات تخص هدف Wasm الكامل وليست دليل فشل بناء الويب العادي.

## التشغيل الأصلي

```bash
flutter run -d android --dart-define=WASEL_LOCAL_ONLY=true
flutter run -d windows --dart-define=WASEL_LOCAL_ONLY=true
flutter build apk --release \
  --target-platform android-arm64 \
  --dart-define=WASEL_LOCAL_ONLY=true
```

توقيع debug مناسب للتطوير والتجربة فقط. يتطلب إصدار عام توقيع إصدار مُدارًا بأمان، وفحوصات الخصوصية والصلاحيات على أجهزة فعلية.

## الاختبارات وفحوصات الجودة

```bash
flutter analyze --no-fatal-infos --no-fatal-warnings
flutter test --concurrency=1
dart run tool/check_file_lengths.dart
dart run tool/check_screen_bindings.dart
dart run tool/check_sqlite_singleton.dart
```

التشغيل التسلسلي مهم لاختبارات SQLite. اختبار واجهة Flutter يُشغّل عمليات FFI عبر `tester.runAsync` كي لا تنتظر ساعة `WidgetTester` الوهمية I/O حقيقيًا.
يفحص GitHub Actions الملفات والاختبارات ثم يبني Web release بوضع المراجعة المحلي؛ لا يقوم الـworkflow باستضافة النسخة.

## حدود مهمة قبل أي إصدار عام

- وضع الويب الحالي **محلي أحادي المستخدم**: لا خادم، لا مزامنة، لا عزل مستخدمين من جهة الخادم، ولا صلاحيات/سياسات صفوف سحابية. `SharedPreferences` والمصادقة المحلية ليست بديلًا عن خدمة مصادقة إنتاجية.
- بيانات المعاينة اصطناعية. موصلات WhatsApp/SMS/Messenger ليست في هذه النسخة تكاملات إنتاجية موثقة؛ لا تعتبرها اتصالًا حقيقيًا بمجرد ظهور شاشة الموصل.
- النسخ الاحتياطي المشفر يعتمد مفتاحًا محليًا في مخزن الجهاز/المتصفح. يلزم تصميم آلية استعادة محمولة بمفتاح/عبارة مرور قبل الاعتماد على ملف النسخة عند تبديل المتصفح أو الجهاز.
- اعتماد `sqflite_common_ffi_web` في المتصفح موصوف كتجريبي من الحزمة؛ يلزم اختبار المتصفحات والأجهزة والأحجام والنسخ والاستعادة والتعامل مع انقطاع التبويب قبل الإطلاق.
- نشر واجهة ثابتة وحده لا يحقق جاهزية المنتج المالي أو تدقيق الأرصدة والعملات والصلاحيات.
