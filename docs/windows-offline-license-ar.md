# الترخيص غير المتصل لـWindows

تتطلب نسخ Wasel Release على Windows ملف ترخيص موقّعاً ومربوطاً بمعرّف الجهاز. يظهر المعرّف في شاشة التفعيل، ويمكن نسخه وإرساله إلى مسؤول الترخيص. يتم اشتقاقه محلياً من `MachineGuid` في سجل Windows، مع UUID الخاص باللوحة/النظام إن توفر؛ تُعرض بصمة مختصرة فقط، ولا تُرسل القيم الخام إلى أي خادم. الترخيص دائم بلا انتهاء تلقائي.

يصدر المسؤول ملف JSON موقّعاً رقمياً بـEd25519. يحمل التطبيق المفتاح العام للتحقق فقط؛ أما مفتاح التوقيع الخاص فيبقى لدى مالك المنتج. لا تضف المفتاح الخاص أو ملفات الترخيص الصادرة إلى Git أو إلى مثبت Windows. كل ملف صالح لجهازه المحدد، ونسخه إلى جهاز ذي معرّف مختلف يُرفض.

## إصدار ترخيص

انسخ مفتاح الإصدار الخاص وسجل التراخيص إلى تخزين آمن خارج المستودع. من جذر المشروع شغّل:

```sh
dart run tool/issue_device_license.dart \
  --device-id "معرّف-الجهاز-الذي-يعرضه-التطبيق" \
  --licensee "اسم العميل" \
  --private-key "/مسار-آمن/issuer-seed.hex" \
  --registry "/مسار-آمن/issued-licenses.json" \
  --output "/مسار-التسليم/wasel-license.json"
```

الأداة تنشئ رقماً فريداً للترخيص وتسجّل ربطه بالجهاز في `issued-licenses.json`. عند إعادة إصدار الملف للترخيص نفسه على الجهاز نفسه مرّر `--license-id` بالقيمة المسجلة/الموجودة في الملف السابق. ترفض الأداة ربط رقم الترخيص المسجل بمعرّف جهاز مختلف. يحتفظ مالك المنتج بنسخة احتياطية آمنة من المفتاح الخاص والسجل؛ فقدان المفتاح الخاص يمنع إصدار تراخيص جديدة بهذا المفتاح.

## حدود الترخيص غير المتصل

لا يتطلب التفعيل اتصالاً بالإنترنت ولا توجد آلية إلغاء فوري بعد إصدار الملف. إذا أُعيد تثبيت Windows أو تغيّر مكوّن يغيّر بصمة الجهاز، يلزم طلب ترخيص جديد. حذف ربط الترخيص من سجل الإصدار لا يعطّل ملفاً قديماً سبق تسليمه، لذلك لا يمكن نقل الترخيص بأمان إلى جهاز آخر دون بقاء النسخة القديمة قابلة للتشغيل.

هذا الربط يوقف الاستخدام العادي لملف ترخيص منسوخ على جهاز مختلف، لكنه ليس DRM غير قابل للكسر: يمكن لمستخدم خبير تعديل برنامج العميل، وقد ينجح استنساخ صورة نظام مع نفس معرّفات الجهاز. لا تُسوّق آلية الترخيص على أنها حماية قطعية من النسخ أو التلاعب.

التحقق مفعّل في نسخ Windows المبنية بوضع Release فقط. الاختبارات ووضع التطوير لا يتطلبان ملف ترخيص.
