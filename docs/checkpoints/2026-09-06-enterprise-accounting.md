# نقطة تفتيش Enterprise Accounting — 2026-09-06

تمت ترقية التطبيق دون بناء APK وفق طلب المرحلة.

## المنجز

أصبح SQLite يتضمن شجرة حسابات قابلة للتوسع، حسابات صندوق وبنك وعملاء وموردين، جدول الجهات، الملف المؤسسي، ملف المستخدم، أسطر القيود، إعدادات الموصلات، وربطًا آمنًا بطابور المزامنة.

سند القبض والصرف والقيد اليومي يدعم الآن رقم السند، البيان، المبلغ، اسم المستلم أو المستفيد، الحساب المدين، الحساب الدائن، وأسطرًا متوازنة داخل معاملة SQLite واحدة. ويتم رفض السند ذي المبلغ غير الصحيح أو القيد غير المتوازن.

تمت إضافة استيراد دليل الحسابات من Excel مع مطابقة الأعمدة العربية والإنجليزية، التحقق من الكود والاسم، تسجيل عدد المستورد والمتجاوز، وإضافة سجل تدقيق.

تم تطوير شاشة الحسابات لإظهار أرصدة الصندوق والبنوك من قاعدة البيانات، إضافة الحسابات، استيراد Excel، العملاء والموردين، التقرير المالي المختصر، سجل التدقيق، وبيانات الشركة للطباعة مستقبلًا. كما أضيف اسم المستخدم إلى مسار إنشاء الحساب.
