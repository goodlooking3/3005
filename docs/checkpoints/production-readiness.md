# بوابة الجاهزية للإنتاج

## الحالة الحالية

الإصدار الحالي هو `0.2.0-preview`. تم تثبيت تجربة الواجهة الأساسية، بنية SQLite، نموذج المحاسبة، تصدير Excel/PDF، بنية الموصلات، خدمة Android Notification Listener، النسخ الاحتياطي JSON، وفحص GitHub Actions للتحليل والاختبارات.

## شروط الإغلاق قبل APK

لا يتم بناء APK release قبل تحقق البنود الآتية على جهاز Android حقيقي:

| المجال | شرط الإغلاق |
|---|---|
| الإشعارات | اختبار Notification Access، استئناف الخدمة بعد إعادة التشغيل، ومنع التكرار |
| WhatsApp | استخدام WhatsApp Business Platform الرسمي أو موصل مصرح، مع إدارة الرموز دون تخزين مكشوف |
| الحسابات | قيود مزدوجة، سندات قبض وصرف، تقارير شهرية، واختبار أرصدة متعددة العملات |
| البيانات | تشفير النسخ الاحتياطية، استعادة ذرية، ومعالجة التعارضات قبل المزامنة |
| الهوية | تسجيل الهاتف/البريد، استعادة كلمة المرور، وقفل بيومتري عبر Android Keystore |
| التصدير | اختبار Excel/PDF والطباعة على أجهزة فعلية ومسارات عربية |
| الأمان | سجل تدقيق، صلاحيات أقل، منع تسريب محتوى الرسائل، واختبار الصلاحيات |
| الجودة | اختبارات الوحدة والتكامل وواجهات المستخدم على Android وWindows |

## قرار البناء

تم تأجيل `flutter build apk --release` عمدًا حتى اكتمال البنود السابقة، كما طلب صاحب المشروع. هذه البيئة لا تحتوي Android SDK حاليًا، لذلك سيُنفذ البناء النهائي في بيئة CI/Android مجهزة بعد إغلاق بوابة الجاهزية.
