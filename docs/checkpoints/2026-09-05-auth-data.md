# نقطة تفتيش الهوية والبيانات — 2026-09-05

تمثل هذه النقطة الإصدار `0.3.0+3` من واصل.

## الإضافات

تمت إضافة بوابة دخول محلية تدعم إنشاء الحساب بالبريد وكلمة مرور، وتسجيل الدخول بالبصمة عبر `local_auth` وAndroid Biometric API. كما تم تسجيل صلاحية `USE_BIOMETRIC` في Android Manifest.

تم ربط تشغيل لوحة التحكم بقاعدة SQLite المحلية. عند أول تشغيل يتم إدخال سجلات البداية إلى قاعدة البيانات، وبعد ذلك تُقرأ السجلات المحفوظة من SQLite بدل الاعتماد على بيانات واجهة ثابتة.

## التحقق

- `flutter analyze`: ناجح بدون أخطاء.
- `flutter test`: جميع الاختبارات ناجحة.
- APK release: مؤجل حتى بوابة الإغلاق الإنتاجي النهائية.

## الحدود المعروفة

الحساب المحلي مناسب للمعاينة والأجهزة الفردية. قبل الإنتاج يجب نقل التحقق إلى خدمة هوية آمنة، واستخدام تخزين أسرار/رموز محمي، وإكمال تدفق استعادة كلمة المرور وربط الحسابات متعددة الأجهزة.
