# نقطة تفتيش الأمان والمزامنة — 2026-09-05

## الإضافات

تم تحويل النسخ الاحتياطي في الواجهة إلى صيغة مشفرة باستخدام AES-GCM، مع حفظ مفتاح التشفير داخل Flutter Secure Storage بدل ملف عادي. تم إضافة تحقق من إصدار envelope ومخطط البيانات قبل الاستعادة.

تمت إضافة مفاتيح idempotency لطابور المزامنة، وتسجيل الإصدار البعيد، وإرسال العناصر المعلقة كاملة إلى endpoint آمن عبر HTTPS. عند وصول HTTP 409 يتم تسجيل التعارض في سجل التدقيق بدل اعتباره نجاحًا، ولا يتم تعليم العناصر بأنها متزامنة إلا بعد استجابة ناجحة.

تمت إضافة عقود موصلات قابلة للاختبار لـ Webhook وموصلات الرسائل الرسمية، مع رفض Webhook غير الآمن الذي لا يستخدم HTTPS.

## نتائج التحقق

- `flutter analyze`: ناجح بلا أخطاء.
- `flutter test`: 6 اختبارات ناجحة.
- APK release: ما زال مؤجلًا حتى إغلاق اختبار الخادم الرسمي والجهاز الحقيقي.

## المتطلبات المتبقية قبل الإنتاج

يجب ربط endpoint إنتاجي حقيقي، وتطبيق سياسة تدوير الرموز، واختبار تعارضات متعددة الأجهزة، وإجراء اختبار اختراق للصلاحيات، والتحقق من WhatsApp Business Platform وSMS بمفاتيح منفصلة عن بيئة التطوير.
