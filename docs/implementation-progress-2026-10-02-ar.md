# واصل — سجل تنفيذ خطة الارتقاء

**التاريخ:** 2026-10-02  
**الفرع:** `main`  
**نوع البناء:** Flutter Web release محلي، SQLite/WASM، `WASEL_WEB_REVIEW=true` و`WASEL_LOCAL_ONLY=true`

## ما تم تنفيذه

### صحة البيانات والمحاسبة

- منع ترحيل السندات إلى الحسابات التجميعية داخل `AccountingRepository`، لا في الواجهة فقط.
- منع تكرار رقم السند قبل إنشاء أي صف؛ التحقق داخل المعاملة يحافظ على الذرية.
- إضافة فحص دورة شجرة الحسابات متعددة المستويات عند تحديث الحساب.
- تعديل `AccountingLedgerBridge` لاستخدام حسابات تفصيلية تحت حسابات الإيرادات والمصروفات والتحويلات الوسيطة؛ لم يتم تخفيف قاعدة منع الحسابات التجميعية.

### الواجهات والحالات

- إضافة حالات تحميل وخطأ ومحاولة جديدة في سوق المشتريات.
- منع النقر المكرر أثناء checkout وإظهار حالة الحفظ وإجمالي عدد القطع في السلة.
- حماية checkout من الاستثناءات مع رسالة عربية، وعدم إفراغ السلة إلا بعد نجاح الحفظ.
- إضافة معالجة خطأ لتصفية وحفظ حركات المحفظة في `WalletProvider`.
- إضافة تسجيل خروج صريح من الإعدادات وإلغاء حالة التذكر على الجهاز.
- تغيير تسمية مؤشر الاتصال من «مزامنة جاهزة» إلى «إعداد مزامنة» عند وجود إعداد فقط؛ وجود endpoint لا يثبت health check أو مزامنة ناجحة.

### الهوية والنسخ

- رفع الحد الأدنى لكلمة المرور إلى 8 أحرف في الخدمة والواجهة.
- إضافة حد 25MB للنسخ المشفرة.
- إضافة تحقق من JSON والغلاف وحقول `nonce/cipherText/mac` قبل فك النسخة.
- تحويل أخطاء النسخ التالفة أو غير المدعومة إلى `FormatException` عربية واضحة.

## حدود لم تُغلق بعد

- المصادقة ما زالت محلية؛ لم تُنفذ هوية خادمية أو KDF إنتاجي أو استرداد متعدد المستخدمين.
- مفتاح النسخة المشفرة محلي مرتبط بالجهاز/المتصفح؛ النقل بين جهازين غير معلن كمدعوم.
- لا يوجد backend أو sync API إنتاجي مثبت؛ `ProductionConfig` و`sync_queue` لا يثبتان مزامنة فعلية.
- Bank Sandbox وموصل الرسائل ليسا تكاملات إنتاجية.
- لا يوجد قبول يدوي على Android/Windows حقيقي، ولا keystore أو endpoint إنتاجي ضمن هذه الدورة.
- تحذيرات Wasm تخص اعتماد `image`؛ بناء Web العادي نجح ولا ينبغي تفسير التحذير كفشل في الهدف الحالي.
